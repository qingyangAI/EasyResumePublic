# EasyResume - 简历制作工具

一个简洁、易用的在线简历制作工具，专注于内容编写，无需担心格式问题。

## 功能特性

- 📝 **可视化编辑**：直观的表单编辑界面，轻松填写简历信息
- 👁️ **实时预览**：随时切换预览模式，查看最终效果
- 💾 **本地存储**：自动保存到浏览器本地存储，数据安全可靠
- 📄 **PDF导出**：一键导出为PDF格式，方便打印和分享
- 🖨️ **打印支持**：优化的打印样式，直接打印简历
- 🎨 **极简设计**：简洁优雅的界面设计，专注于内容本身

## 技术栈

- React 18
- Vite
- TailwindCSS
- html2canvas
- jsPDF

## 快速开始

### 安装依赖

```bash
npm install
```

### 启动开发服务器

```bash
npm run dev
```

访问 http://localhost:3000

### 构建生产版本

```bash
npm run build
```

### 预览生产版本

```bash
npm run preview
```

## 使用说明

1. **编辑简历**：在编辑模式下填写个人信息、工作经历、项目经历等内容
2. **预览效果**：点击"预览"按钮查看最终简历效果
3. **保存数据**：点击"保存"按钮将简历数据保存到本地存储
4. **导出PDF**：在预览模式下点击"导出PDF"按钮生成PDF文件
5. **打印简历**：在预览模式下点击"打印"按钮直接打印简历

## 简历模块

- 个人信息（姓名、职位、联系方式等）
- 专业标签
- 个人优势
- 荣誉证书
- 工作经历（支持多段经历，包含工作业绩和工作内容）
- 项目经历（支持多个项目，包含详细描述）
- 教育背景
