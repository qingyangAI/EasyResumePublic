# Issue: 数据导入导出功能增强

## 需求描述

### 需求1: 默认数据为空，支持JSON导入导出备份和还原

**背景**：
- 当前系统默认包含示例数据，新用户需要手动清空
- 用户需要能够备份和还原简历数据

**需求**：
1. 系统启动时默认数据为空，不包含任何示例内容
2. 支持将简历数据导出为JSON格式文件
3. 支持从JSON文件导入简历数据
4. 导入的数据能够完整还原所有简历信息

**预期效果**：
- 新用户打开系统时看到的是空白表单
- 用户可以随时导出JSON文件进行备份
- 用户可以导入之前导出的JSON文件恢复数据

---

### 需求2: 增加Excel模板导入导出功能

**背景**：
- 部分用户不熟悉JSON格式，更习惯使用Excel
- 需要提供更友好的数据录入方式

**需求**：
1. 支持下载Excel填写模板，模板包含所有简历字段
2. 支持将简历数据导出为Excel格式
3. 支持从Excel文件导入简历数据
4. 导入导出支持两种格式：JSON和Excel
5. Excel模板应包含清晰的字段说明，方便非技术用户填写

**预期效果**：
- 用户可以下载Excel模板，在Excel中填写后导入
- 用户可以选择导出为JSON或Excel格式
- 用户可以选择导入JSON或Excel格式的文件
- Excel模板结构清晰，易于理解和填写

---

## 技术实现

### 已实现功能

1. **默认数据为空**
   - 修改 `GetDefaultResumeData()` 函数，返回空数据结构
   - 所有字段初始值为空字符串或空数组

2. **JSON导入导出**
   - `ExportResumeJSON()`: 导出简历数据为JSON文件
   - `ImportResumeJSON()`: 从JSON文件导入简历数据
   - 支持完整的错误处理和用户提示

3. **Excel导入导出**
   - `DownloadExcelTemplate()`: 下载Excel填写模板
   - `ExportResumeExcel()`: 导出简历数据为Excel文件
   - `ImportResumeExcel()`: 从Excel文件导入简历数据
   - 使用 `xlsx` 库处理Excel文件

4. **UI界面优化**
   - 添加"下载模板"按钮
   - "导出"按钮支持下拉菜单选择格式（JSON/Excel）
   - "导入"按钮支持下拉菜单选择格式（JSON/Excel）
   - 所有操作都有成功/失败提示

### Excel模板结构

Excel模板包含以下工作表：
- 个人信息
- 作品集
- 专业标签
- 个人优势
- 荣誉证书
- 工作经历
- 工作业绩
- 工作内容
- 项目经历
- 项目描述
- 教育背景
- 在校成就
